# Telecom X - Previsão de Churn

Este projeto tem como objetivo prever a evasão de clientes (churn) utilizando modelos de Machine Learning.

## Etapas do Projeto

* Limpeza e pré-processamento dos dados
* Análise exploratória de dados (EDA)
* Engenharia de variáveis (Feature Engineering)
* Treinamento de modelos de Machine Learning
* Avaliação de desempenho dos modelos
* Geração de insights estratégicos para o negócio

## Tecnologias Utilizadas

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn
